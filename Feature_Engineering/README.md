# Feature Engineering 🧩

## Overview
Feature Engineering is one of the most important steps in the Machine Learning pipeline.  
This folder contains my **learning notes, experiments, and practical implementations**
related to transforming raw data into meaningful features that improve model performance.

The goal of this section is to understand **why**, **when**, and **how** different feature
engineering techniques are applied in real-world data science problems.

---

## Topics Covered

### 🔹 Data Cleaning & Preprocessing
- Handling missing values (mean, median, mode, forward/backward fill)
- Removing duplicates
- Treating outliers (IQR, Z-score)
- Data type corrections

### 🔹 Encoding Techniques
- Label Encoding
- One-Hot Encoding
- Ordinal Encoding
- Target Encoding (conceptual understanding)

### 🔹 Feature Scaling
- Standardization (Z-score scaling)
- Min-Max Scaling
- Robust Scaling
- When scaling is required and when it is not

### 🔹 Feature Transformation
- Log transformation
- Power transformation
- Handling skewed data
- Binning and discretization

### 🔹 Feature Creation
- Creating new features from existing ones
- Date & time feature extraction
- Aggregated features (groupby-based features)
- Domain-based feature creation

### 🔹 Feature Selection
- Correlation analysis
- Variance threshold
- SelectKBest
- Model-based feature importance

## Learning Outcome
Through this module, I learned how proper feature engineering:
- Improves model accuracy and stability
- Reduces overfitting
- Makes models more interpretable
